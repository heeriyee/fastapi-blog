# FastAPI Blog

A beginner-friendly blog web application built while following Corey Schafer's FastAPI tutorial.

## Features

- FastAPI backend
- REST API endpoint for blog posts
- HTML blog page
- Automatic API documentation with Swagger UI

## Tech Stack

- Python
- FastAPI
- HTML
- Git and GitHub

## Run Locally

1. Clone the repository.
2. Create and activate a Python virtual environment.
3. Install FastAPI:

   ```bash
   python -m pip install "fastapi[standard]"
   ```

4. Start the development server:
   fastapi dev main.py
  

5. Open `http://127.0.0.1:8000/blog` in your browser.

## Learning Goals

Understand API routes, HTTP GET requests, JSON responses, HTML responses, and backend development fundamentals.
